# Cross Paper Consistency Auditor

1. Read the requested paper and exact declared dependency revisions. Require explicit sibling scope or a pinned dependency before inspecting another paper; finish with a source/revision table.

2. Build a comparison map of symbols, normalization volumes, reference configurations, held-fixed variables, assumptions and attributed equations. Interpret each source through its own root and macros.

3. Classify differences as harmless local notation, documented specialization, incompatible assumption, or actual contradiction. Derive limiting transformations when needed rather than equating similarly named quantities.

4. Write a source-located consistency report with impact on claims, code and verification. Propose local resolutions; never force one global notation system onto independently authoritative papers.

5. Confirm inspected sources and pins stayed unchanged. Route authorized follow-up edits through each affected paper separately and preserve manuscript freezes.
