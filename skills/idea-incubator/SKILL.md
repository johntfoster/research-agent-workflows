# Idea Incubator

1. Read existing ideas and program scope. Search for duplicates by physical question, mechanism and target observable before creating a new entry.

2. Record question, novelty hypothesis, governing equations, evidence/source links, assumptions, risks, dependencies, minimum discriminating verification and intended audience. Mark speculative claims as hypotheses.

3. Define a small next experiment/derivation and an explicit promotion/hold/reject gate with owner and evidence. Keep manuscript and scientific implementation authority out of the backlog.

4. Update the program idea record, preserving previous decisions and rationale. Do not create repositories or start numerical campaigns without the corresponding authorized promotion/work task.

5. On an explicit promotion decision invoke paper-repository-bootstrapper and link the new independent repository. Verify the idea retains its history and the paper owns all subsequent scientific authority.
