# Artifact Consistency Coordinator

1. Identify the requested quantity/figure and inventory all consumers: generator, source data, curated result, manuscript figure/caption, site asset and release package. Record current checksums.

2. Read generation parameters, units, time/space sampling, provenance and caption claims. Distinguish reference data, transient output and publication assets.

3. Plan one coordinated update with source authority and required verification. If a manuscript consumer is frozen, report the dependency and stop that update rather than changing only its other consumers.

4. For an authorized unfrozen update regenerate from recorded inputs, inspect the figure and numerical values, update all consumers, and refresh checksums. Do not substitute stale/cached values for a new run.

5. Check every consumer points to the intended artifact and source revision. Report inaccessible publication surfaces and do not claim consistency from matching filenames alone.
